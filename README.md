<p align="center"><strong>GTA: Vice City</strong></p>

A single-file browser port with a small launcher and local saves.

Core files load first, radio downloads run in the background, and verified downloads are cached for later visits. Five CDN routes provide fallback when a file fails to load. Saves stay in the browser, with manual export/import for moving them to another site.

The launcher adds graphics presets, fullscreen, storage controls, and a cleaner interface. The game build stays the same. Some upstream game assets are still missing; cached play is supported, but this is not a complete offline installation.

**Run it:** serve `GTA_Vice_City.html` over HTTPS or localhost, then press Play. Use **Load Game** to resume a saved slot. Save through the game's normal save slots. Export before moving hosts or clearing browser data.
